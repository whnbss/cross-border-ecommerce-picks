# bagisto — 一条 docker 命令交付一个零月租独立站

> **一句话结论**：推荐 **bagisto/bagisto**，MIT 许可的 Laravel 电商系统，`docker run` 一条命令就能起一个带前后台的完整商城。最适合**接私活做独立站交付的开发者/小工作室**——客户不想交 Shopify 月租和交易抽成时，这就是你的报价武器。

## 它是干什么的

Laravel + Vue 写的开源电商系统，单商户店、B2B、多商户 marketplace、多租户 SaaS、POS、headless（Next.js 前台）都在它的产品线里。核心价值很直接：**不用给平台交月租和抽成，数据在自己手上**。README 明确给了 `docker run` 一行命令的安装方式，镜像里已经烤好迁移、种子数据和搜索索引，没有首次安装步骤。另带 200+ 扩展市场和一套 Flutter 移动端。

## 落地步骤（今天就能跑起来）

```bash
# 1. 装 Docker Desktop（Windows/macOS）或 docker engine（Linux），确认可用
docker --version

# 2. 一条命令起完整商城（镜像自带迁移、种子数据、搜索索引）
docker run -d --name bagisto -p 80:80 webkul/bagisto:latest

# 3. 打开前台，确认站点活着
#    Windows 浏览器访问：http://localhost
#    Linux 服务器：http://<你的公网IP>

# 4. 管理员入口、账号密码、换数据库（MySQL/MariaDB/PostgreSQL）、接外部 DB
#    全部在仓库 docker/production/README.md 里，按该文件操作
curl -sL https://raw.githubusercontent.com/bagisto/bagisto/2.5/docker/production/README.md | head -60

# 5. 换成可交付形态：固定版本 + 自己的域名 + HTTPS
docker rm -f bagisto
docker run -d --name shop -p 80:80 webkul/bagisto:2.5.0-nginx-postgres
```

生产环境记得挂数据卷、配 HTTPS 反代、改掉默认管理员密码——这三件事不做就别交给客户。

## 风险与坑

- **商业扩展边界**：README 把 B2B、多商户、多租户、POS 都列成产品线，但**哪些能力在免费仓库里、哪些要买官方商业扩展，落地前必须逐项核对**。给客户报价时把"扩展授权费"单独列出来，别自己吞。
- **支付/物流靠插件**：跨境收款（Stripe/PayPal/本地钱包）、物流面单基本走第三方扩展或自研，这部分工作量常被低估。
- **自托管 = 自己扛安全**：客户数据、PCI 相关的支付合规、GDPR、订单备份，都是你的责任。至少配自动备份 + 每日健康检查。
- **维护状态**：26 个 open issue，2026-11-18 仍有推送，主分支在 2.5，属于健康维护中；但 PHP 生态升级（Laravel 大版本）需要你跟进。
- **别把它当 Shopify 平替直接卖**：Shopify 卖的是支付、物流、风控、客服的一整套；Bagisto 卖的是"可控 + 零抽成"。卖给错的客户（不懂技术、想要开箱即用）会变成长期售后黑洞。
