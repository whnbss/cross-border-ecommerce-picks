## 它是干什么的

一行命令把图片背景去掉，输出带透明通道的 PNG。五个子命令覆盖全部场景：`i` 单张、`p` 整个文件夹（还能 `-w` 盯着目录自动处理新文件）、`s` 起一个 HTTP 服务、`b` 从 stdin 吃 RGB24 流（可以直接接 FFmpeg 处理视频）、`d` 预先下模型。模型可换：u2net 系列、isnet、SAM、BiRefNet，以及默认的 bria-rmbg。

## 落地步骤（今天就能跑起来）

```bash
# 1. 装（CPU 版够用；有 NVIDIA 卡再换 gpu 版，需自备 CUDA/cudnn）
pip install "rembg[cpu,cli]"

# 2. 单张试
rembg i input.jpg output.png

# 3. 批量处理整个目录，并顺手做边缘去色（推荐，代价可忽略）
rembg p -dc ./raw ./out

# 4. 盯目录：新图丢进去自动出结果，适合当"共享文件夹"给同事用
rembg p -w ./inbox ./done

# 5. 起 HTTP 服务，供上架系统/脚本调用
rembg s --host 0.0.0.0 --port 7000
curl -s -F file=@input.jpg "http://localhost:7000/api/remove" -o out.png

# 不想装 Python 就用 Docker
docker run -v .:/data danielgatis/rembg i /data/input.png /data/output.png
```

商用记得换模型：`rembg p -m isnet-general-use ./raw ./out`（默认的 bria-rmbg 有商用限制，见下）。

## 风险与坑

- **模型许可 ≠ 代码许可（今天最重要的一条）**：rembg 代码是 MIT，但权重各自独立。README 明确写：默认模型 **bria-rmbg（RMBG-2.0）需要付费协议才能商用**。给客户交付前，要么买 BRIA 授权，要么显式切到 `-m u2net` / `-m isnet-general-use` / `-m birefnet-general` 并逐个核对这些模型的许可。这条不查清，接单就是给自己埋雷。
- **质量因品类而异**：硬边商品（3C、五金、包装盒）默认模式就够；毛发、纱料、透明玻璃、珠宝反光这些软边，需要 `-dc` 去色、`-a` 或 `-vm` 做 alpha 修边，而且仍可能返工。
- **速度**：默认 bria 模型约 1GB，按 1024×1024 推理，CPU 上慢；批量几百张建议 `-m u2net` 或上 GPU。
- **主图规范是平台规则，不是技术问题**：亚马逊白底要求、留白比例、不能有道具，抠完还要按平台模板裁切，别只交透明 PNG。
- **维护状态**：2 个 open issue、2026-11-06 仍有推送、Docker 镜像持续更新，是本系列里维护得最干净的项目之一。
