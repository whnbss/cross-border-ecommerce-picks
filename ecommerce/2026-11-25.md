## 它是干什么的

一层支付编排中间件：商户接一次 API，底下可以挂 Stripe、Adyen、Checkout.com、Worldpay、Cybersource 等 120+ 通道。核心能力是六个模块——**智能路由**（按预测授权率把每笔交易分发给最可能成功的 PSP）、**收入挽回**（按卡 BIN、地区、支付方式差异化重试）、**成本可观测**（发现隐藏费用、降级、罚金）、**Vault**（PCI 合规的卡与 token 存储）、**对账**（双向/三向自动对账）、**替代支付方式**（Apple Pay / Google Pay / Klarna / BNPL 一键组件）。

## 风险与坑

- **你要先有商户号，这是真正的门槛**：Hyperswitch 是编排层，不提供收单资质。想做跨境收款，得有境外主体 + Stripe/Adyen 等商户号；没有的话，这套东西装了也跑不出钱。
- **PCI 合规范围会变大**：一旦自托管并存储卡数据，你就进入 PCI DSS 范围。项目自带 Vault 和加密服务，但**合规审计的责任在你自己**，不是装完就合规。
- **运维复杂度是 Rust 多服务**：app server + card-vault + encryption-service + control-center，生产还要监控与调度；小团队容易装得起来、稳不住。
- **2,389 个 open issue**：项目极活跃，但 issue 堆积也多，遇到坑要能自己读代码。
- **许可证与品牌**：代码 Apache-2.0，可商用可改；但 README 自称 "commercial open-source"，对外宣传时别用它的商标做背书。
- **通道能力差异**：每个 PSP 支持的支付方式、币种、退款流程不同，路由规则要按真实数据调，不能开箱即最优。
