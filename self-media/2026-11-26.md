## 它是干什么的

节点图的 AI 生成引擎：把模型、采样器、ControlNet、LoRA、放大、抠图、插帧、分割这些能力做成可连线的节点，连好一次就能反复跑、批量跑。原生支持当下主流的图像、视频、音频、3D、文本模型（Flux.2、Qwen Image、Wan 2.2、LTX-Video、Hunyuan3D 等），4GB 显存 + 8GB 内存就能跑起来（异步权重流式加载）。生成的文件拖回画布，**能还原出完整的原始工作流**，种子都在。

| **2. 工作流定制售卖** | 把"一键出电商主图""一键出门头图文"打包成 workflow 或 App Mode 小工具，卖给同行 | 同上 | ★★★★☆ 中高 |
| **3. 矩阵号图文供给** | 一个选题批量产出十几张配图与封面变体，供多账号排期 | 同上 | ★★★☆☆ 中 |
| **4. 内部产线替外包** | 给公司把设计外包的一部分（banner、活动图、SKU 场景图）转成内部流水线 | 显卡 + 调试时间 | ★★★★☆ 中高 |

App Mode 是第 2 条的关键：工作流能收成一个只有输入框和按钮的简单界面，客户不用懂节点。

## 落地步骤（今天就能跑起来）

```bash
# 路线 A：桌面版（Windows/macOS，装完即用，最省事）
# 到 comfy.org/download 下安装包

# 路线 B：命令行安装
pip install comfy-cli
comfy install

# 路线 C：手动装（要自己控制 Python / Torch 版本时）
git clone https://github.com/Comfy-Org/ComfyUI.git
cd ComfyUI
pip install -r requirements.txt
python main.py
# 模型放 models/checkpoints，VAE 放 models/vae
# Python 3.13 支持最好；N 卡 20 系以上建议 torch cu130 或更新

# 首次跑通后：装 ComfyUI-Manager 管理自定义节点，从 comfy.org/workflows 拉现成模板
# 想接自动化：用本地 API（/prompt 提交工作流 JSON），或 --offline 彻底断网只跑本地
```

## 风险与坑

- **GPL-3.0 的边界要弄清**：自己用、接单出图，产出物不受传染；但**对外分发修改过的 ComfyUI 或打包售卖**，要按 GPL 提供源码。做 SaaS 给客户远程用属于灰色地带，别想当然。
- **自定义节点是最大的安全隐患**：装一个第三方节点就等于让陌生人在你机器上跑 Python。只装 star 多、最近有更新的仓库，生产环境考虑单独容器/虚拟机隔离，别在有财务数据的机器上乱装。
- **模型许可各不相同**：Flux、SD、各家视频模型对商用的限制不一样，出商用图前逐个确认，这跟软件许可证是两回事。
- **5,648 个 open issue**：项目极大且迭代快，遇到问题先查 troubleshooting——README 明说"加各种启动参数提速"多半是反效果。
- **显卡与电费是真成本**：云端 GPU 按小时计费，批量出图的账要算清；纯 CPU 跑会很慢。
- **版权与肖像**：用他人作品做 LoRA、生成真人肖像用于带货，都可能侵权；平台对 AI 生成内容也有标注要求。
