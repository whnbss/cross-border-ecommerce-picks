## 它是干什么的

把文档变成"能听的书"。输入 ePub、PDF、TXT、Markdown，甚至 SRT/ASS/VTT 字幕文件，输出音频 + **时间轴对齐的字幕**。支持分章保存、合并成 M4B（带章节与元数据、自动嵌封面）、队列批量处理、自定义音色混音。Web 端还能接 OpenAI 兼容的模型做"文本规范化"（处理缩写、生僻符号），以及把成品直接推进 Audiobookshelf 书架。

## 落地步骤（今天就能跑起来）

```bash
# Windows：先装 espeak-ng（msi），再跑仓库里的 WINDOWS_INSTALL.bat，自带 Python 环境

# 通用（推荐 uv，能锁 CUDA 版本）
uv tool install --python 3.12 abogen[cuda] --extra-index-url https://download.pytorch.org/whl/cu128 --index-strategy unsafe-best-match
# 没有 N 卡就用：uv tool install --python 3.12 abogen

abogen          # 桌面 GUI：拖入文件 → 选音色/语速/字幕样式 → Start
abogen-web      # Web UI：http://localhost:8808 ，支持队列与后台任务

# Docker（Web 端）
docker build -t abogen .
docker run --rm -p 8808:8808 -v ~/abogen-data:/data --name abogen abogen
```

中文/日文要额外装语言包：`pip install misaki[zh]` / `misaki[ja]`。

## 风险与坑

- **外语字幕只有句级**：README 明确写了——词级字幕（1 词/2 词/3 词）**只支持英文**，因为 Kokoro 只给英文提供时间戳 token；非英文走时长回退，只能用 Line / Sentence / Sentence + Comma 这几种样式。做中文卡点字幕要另找工具。
- **版权是硬约束**：ePub/PDF 的著作权在作者或出版社，没有授权就做成有声书上架，是侵权不是"技术活"。接单前要授权书。
- **朗读质量看文本**：多音字、专业术语、公式、表格都会读错；长篇必须先跑一章试听，再整本批量，否则返工成本极高。
- **平台规则**：有声书平台对独家授权、AI 合成声明有各自要求，上架前逐条核对。
- **依赖装起来烦**：espeak-ng 必须单独装，CUDA 版本与 PyTorch 要匹配，Windows 上 AMD 卡不支持（只能 Linux + ROCm）——报错大多来自这里。
- **维护状态**：52 个 open issue、2026-11-26 仍在推，作者活跃，Web 端是新加的重构（还在追平桌面端功能）。
