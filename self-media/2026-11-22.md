## 它是干什么的

它不是"再生成一个视频"，而是**替你做剪辑决策**。先用 ElevenLabs Scribe 把每条素材转成带词级时间戳、说话人分离、音频事件的文本（打包成约 12KB 的 `takes_packed.md`），agent 读文本而不是看帧来定剪点：删口癖、删重复、删停顿，切点加 30ms 音频淡入淡出防爆音，统一调色，烧上你风格的字幕，需要动画时再调 HyperFrames/Remotion/Manim 生成叠层。渲染完还会对每个切点做自检，不过关最多重渲 3 次。

## 落地步骤（今天就能跑起来）

```bash
# 1. 基础依赖
brew install ffmpeg            # Windows 用 winget install Gyan.FFmpeg
# 需要一个可用的 agent CLI（Claude Code / Codex 等），并已登录

# 2. 手动安装（比让 agent 自动装更可控）
git clone https://github.com/browser-use/video-use ~/Developer/video-use
cd ~/Developer/video-use
uv sync                        # 或 pip install -e .

# 3. 注册成 agent skill（以 Claude Code 为例）
ln -sfn ~/Developer/video-use ~/.claude/skills/video-use

# 4. 配 ElevenLabs 转录 key
cp .env.example .env
# 编辑 .env，写入 ELEVENLABS_API_KEY=...

# 5. 开始剪
mkdir -p ~/videos/takes && cd ~/videos/takes   # 把素材放进来
claude                                          # 或 codex
# 会话里说：edit these into a launch video
```

产出落在素材旁的 `edit/final.mp4`，会话记忆存在 `project.md`，下次接着剪。

## 风险与坑

- **转录是付费环节**：ElevenLabs Scribe 按分钟计费，长素材、多版本试剪会放大成本；先拿 5 分钟素材跑通再上量。
- **它依赖「外面那层」**：仓库本身是编排层（约 900KB），真正的转录在 ElevenLabs、动画在 HyperFrames/Remotion。任一上游改价或改 API，你的流水线就断，别把它当自包含引擎卖。
- **艺术判断仍有上限**：它能保证切点不跳、不爆音、字幕不错位，但"这条片子好不好看"还得人兜底；对外报价要留返修工时。
- **字幕与专有名词**：品牌名、型号、人名容易转错，交付前必须过一遍字幕；错一个字在带货视频里就是事故。
- **素材与肖像授权**：客户访谈要书面授权，BGM 与字体同样有版权，别拿网图当片头。
- **维护状态**：MIT、3,638 fork、169 个 open issue，最后一次推送 2026-10-08（约一个半月前），属于活跃但不算高频；功能强依赖外部服务，属于"工具链"而非"基础设施"。
