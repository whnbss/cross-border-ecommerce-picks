## 它是干什么的

用阿里 Paraformer 系列做中文语音识别（带时间戳），把视频转成带说话人标记的字幕文本；你在文本里选中一段，它就剪出对应片段，**还能顺手生成整片和片段的 SRT**。三种玩法：手选文字剪、按说话人剪、用 LLM 读完整篇转录后自动挑高光段落再剪。全程本地跑，不需要买第三方 API。

## 落地步骤（今天就能跑起来）

```bash
# 1. 拉代码（需要 Python 3.12）
git clone https://github.com/modelscope/FunClip.git
cd FunClip

# 2. 建虚拟环境并装依赖（先装与平台匹配的 torch/torchaudio）
python3.12 -m venv .venv
. .venv/bin/activate          # Windows: .venv\Scripts\activate
python -m pip install -r requirements.txt

# 3. 启动本地界面
python funclip/launch.py
# 打开 http://localhost:7860

# 4. 换模型 / 换语言（按需）
python funclip/launch.py -l en          # 英文视频
python funclip/launch.py -m sensevoice  # 多语种 + 情绪/事件标签
python funclip/launch.py -s True -p 7861 # 对外提供服务

# 5. 纯命令行跑（不进界面，适合批量）
python funclip/videoclipper.py --stage 1 --file examples/demo.mp4 --output_dir ./output
python funclip/videoclipper.py --stage 2 --file examples/demo.mp4 --output_dir ./output \
  --dest_text '要剪的那句话' --start_ost 0 --end_ost 100 --output_file ./output/res.mp4
```

首次启动会自动下载模型权重（不在源码包里），网络不通就卡在这一步——先确认能访问 ModelScope / HuggingFace。

## 风险与坑

- **版权是硬红线**：切片必须拿到主播或版权方授权。平台对未授权搬运查得很严，轻则限流重则封号，甚至有法律风险（信息网络传播权）。
- **断章取义的法律风险**：把一句话剪出来换个语境，可能构成名誉侵权；做人物类切片尤其要留原始上下文。
- **环境是最常见的坑**：README 明确要求 Python 3.12 且先装匹配的 PyTorch/torchaudio；`Transformers` 必须留在 4.x，别顺手升到 5.x。
- **硬件**：CPU 能跑但慢，长视频吃内存；批量生产建议上 GPU 或分批跑。
- **中文优先**：默认 Paraformer 中文效果最好，英文要显式 `-l en`；日韩等语种用 `-m sensevoice` 更稳。
- **维护状态**：19 个 open issue，最新 v2.2.1（2026-09），2026-11-01 仍有推送，阿里 FunASR 团队维护，健康度好。
