## 它是干什么的

少样本语音克隆 + 文本转语音的 WebUI 工具箱。两种用法：**零样本**（丢 5 秒音频直接合成）、**少样本微调**（1 分钟干净音频训练专属音色）。自带配套工具链：人声/伴奏分离（UVR5）、自动切分训练集、中文 ASR 打标、文本校对——也就是说从一段粗糙录音到能用的话术配音，全在同一个界面里完成。

## 落地步骤（今天就能跑起来）

```bash
# 路线 A：Windows 整合包（最省事）
# 下载 GPT-SoVITS 整合包，解压后双击 go-webui.bat 直接开界面

# 路线 B：源码安装（Linux / macOS 同流程）
conda create -n GPTSoVits python=3.10 && conda activate GPTSoVits
git clone https://github.com/bilibili/GPT-SoVITS.git && cd GPT-SoVITS
bash install.sh --device CU128 --source HF      # 会自动下预训练模型
conda install ffmpeg

# 路线 C：Docker
docker compose run --service-ports GPT-SoVITS-CU128
#  （Lite 版不含 ASR/UVR5 模型，Windows 下记得把 shm_size 调到 16g）

# 打开 WebUI：python webui.py
# 训练流程：填音频路径 → 切片 → 降噪 → ASR → 校对 → 下一页微调
# 推理入口：1-GPT-SoVITS-TTS/1C-inference
```

模型版本要对齐：v2Pro 性价比最高、v5 相似度最好、v3/v4 更贴参考音频但对素材质量挑剔。

## 风险与坑

- **声音权是第一道红线**：克隆他人声音需**书面授权**。民法典对自然人声音的保护参照肖像权，未经许可克隆网红/明星/客户声音用于商用，是直接侵权。只克隆自己或已签约授权的人。
- **平台标注义务**：抖音、视频号、B 站等对 AI 生成内容有标识要求，纯 AI 配音冒充真人出镜容易限流或处罚。
- **素材质量决定成败**：1 分钟素材必须干净——无 BGM、无混响、无爆音、单人单麦。拿手机在空房间录，比用录音棚素材混着喂更稳。
- **版本地狱**：项目从 v1 迭代到 v5，模型、代码、WebUI 三者版本必须对应；916 个 open issue 里大半是版本/环境问题。**装之前先确定要用哪个版本**。
- **显卡门槛**：CPU 能跑但 RTF 0.526，长文本会等到怀疑人生；批量出活基本要 CUDA。
- **商用许可要分层看**：代码 MIT，但你训练用的底模、ASR 模型、UVR5 权重各有来源，对外交付前逐个核对。
