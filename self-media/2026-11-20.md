## 它是干什么的

把视频写成 HTML：元素加 `data-start` / `data-duration` / `data-track-index` 控制时间和轨道，动画用 GSAP / CSS / Lottie / Three.js 都行。渲染器在无头 Chrome 里逐帧 seek，再用 FFmpeg 编码，**同样的输入永远出同样的片子**——所以能进 CI、能批量跑。附带 450+ 现成组件（转场、字幕、图表、地图、3D）、9 个给 AI agent 用的 skill、以及 AWS Lambda 分布式渲染。

## 落地步骤（今天就能跑起来）

```bash
# 1. 环境：Node.js 22+ 与 FFmpeg
node -v          # 必须是 v22 或更高
ffmpeg -version  # 没有就装（Windows: winget install Gyan.FFmpeg）

# 2. 建项目（不用 clone 整个仓库，仓库带 240MB LFS 测试视频，整仓克隆很慢）
npx hyperframes init my-video
cd my-video

# 3. 浏览器里实时预览
npx hyperframes preview

# 4. 装一个现成组件（转场 / 社交贴片 / 动态图表）
npx hyperframes add flash-through-white
npx hyperframes add data-chart

# 5. 渲染成 MP4
npx hyperframes render
```

想走 agent 路线（让 Claude Code / Codex 直接帮你写片子）：先 `npx hyperframes skills update` 装核心 6 个 skill，再对 agent 说"用 /hyperframes 做一个 10 秒产品开场，带淡入标题和背景音乐"。

## 风险与坑

- **不是"一句话出片"**：核心还是写 HTML/CSS/JS。真正的零代码体验在 Studio 桌面版，而 `reverse-any-video`（反解任意视频）、`style-sampling`（五种成片风格）这两个最省事的 skill 标了 **Pro**，要订阅。
- **素材版权**：音乐、B-roll、人脸、品牌 logo 都得自己保证授权；用 AI 生成的人像做带货口播，平台对"AI 生成内容"有标注要求，不标可能限流。
- **模板同质化**：同一套 catalog 模板批量铺出去，平台容易判重复内容；必须做变量（文案、配色、镜头顺序、BGM）。
- **环境依赖**：Node 22+ 与 FFmpeg 缺一不可，Windows 上 FFmpeg 路径没配好会直接报渲染失败。
- **维护状态**：87k stars、当天还有推送、HeyGen 官方在生产使用，健康度很好；但 Pro 功能与开源核心的边界会随商业策略变化，长期依赖前先确认你要用的能力在 Apache-2.0 覆盖范围内。
