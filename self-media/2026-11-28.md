## 它是干什么的

开源的独立发布平台，官方定位是 "publishing, memberships, subscriptions and newsletters"。写文章、管会员、做付费订阅、发 newsletter 是一体的，也提供 headless 的 Content API，能让前端自己写。下载量官方标记 100M+，还被列为 Digital Public Good。

第 1 条最稳：创作者普遍的痛点是"粉丝在平台手里"，你给的是资产归属。

## 落地步骤（今天就能跑起来）

```bash
# 1. 装官方 CLI
npm install ghost-cli -g

# 2. 本地先跑一个看看（一分钟内起）
mkdir ghost-site && cd ghost-site
ghost install local

# 3. 上服务器（会问域名、自动配 SSL、要 MySQL 凭据）
ghost install

# 4. 后台进 Members/Portal 配会员等级与订阅价格，接 Stripe 收款
# 5. 主题与 API 文档：docs.ghost.org（themes / content-api）
```

## 风险与坑

- **收款是硬门槛，不是技术门槛**：Stripe 收款需要对应主体与结算账户，中国主体个人创作者通常要走境外主体或第三方方案——**没解决收款，站搭得再漂亮也收不到钱**。
- **商标受限**：Ghost 名称与 Logo 是 Ghost Foundation 的商标，README 明确指向其商标政策。你给客户交付时别拿 "Ghost" 做背书式宣传，自建站点要换自己的品牌。
- **自托管就要自己运维**：Node 进程、数据库、备份、升级（Ghost 升级有明确步骤，跳版本容易坏）、SSL 续期，都是长期活儿。想省事就是官方 Ghost(Pro)，但那是付费托管。
- **内容合规是运营方责任**：站是你自己的，侵权、虚假宣传、违规内容没有平台帮你兜底；跨境面向海外读者还要看当地法规与隐私政策。
- **付费转化不靠工具**：Ghost 只解决"能收钱"，能不能收到取决于选题与信任。别把建站当增长。
- **维护状态**：279 个 open issue，2026-11-28 仍在推；官方团队全职维护，是这一批项目里组织化程度最高的。
