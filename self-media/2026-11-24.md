## 它是干什么的

实时流式数字人引擎：输入文字 → LLM 生成回复（可选）→ TTS 合成语音 → 口型模型实时对齐 → WebRTC/RTMP/虚拟摄像头推流。支持 wav2lip、musetalk、ernerf、Ultralight 四种模型，支持声音克隆、被打断后重说、不说话时播放自定义动作视频、多并发。自带三个网页：`/index.html` 体验、`/avatar.html` 上传视频自动生成数字人形象、`/admin.html` 看会话与全局配置。

## 落地步骤（今天就能跑起来）

```bash
# 1. 环境（README 实测 Ubuntu 22.04 + Python 3.12 + PyTorch 2.9.1 + CUDA 12.8）
git clone https://github.com/lipku/LiveTalking.git
conda create -n livetalking python=3.12 && conda activate livetalking
nvidia-smi   # CUDA 版本不是 12.8 就按 PyTorch 官网换对应 cuXXX 源

# 2. 装 torch（以 cu128 为例）与依赖
pip install torch==2.9.1 torchvision==0.24.1 torchaudio==2.9.1 --index-url https://download.pytorch.org/whl/cu128
cd LiveTalking && pip install -r requirements.txt

# 3. 放模型：wav2lip256.pth 重命名为 models/wav2lip.pth
#    wav2lip256_avatar1.tar.gz 解压后整个目录放到 data/avatars/

# 4. 启动（服务端要放行 TCP:8010 与 UDP:1-65536）
python app.py --transport webrtc --model wav2lip --avatar_id wav2lip256_avatar1

# 5. 浏览器打开 http://服务器IP:8010/index.html ，点"开始连接"，输入文字即可
#    自定义形象：/avatar.html 上传一段视频自动生成
```

性能参考（README 实测）：wav2lip256 在 RTX 3060 上 60 FPS、3080Ti 上 120 FPS；musetalk 在 3090 上 45 FPS、4090 上 72 FPS。后端日志里 `inferfps` 和 `finalfps` 都要 ≥25 才算实时。

## 风险与坑

- **开源版有强制水印要求（决定你要不要用它）**：README 第 8 节写明——**基于本项目开发并发布在 B 站、视频号、抖音等平台的视频，需带上 LiveTalking 的水印和标识**。这意味着你给客户交付的成片会带第三方水印；不接受就走付费商用版，或换方案。接单前务必先跟客户确认。
- **平台治理是硬约束**：抖音/视频号等对"无人直播、AI 数字人"有明确规则（需标识、禁止纯录播冒充真人）。用数字人做 24 小时无人直播，被封禁/限流的风险高，且属于平台政策问题，不是技术能绕过的。
- **肖像权**：用真人视频生成形象，必须拿到本人书面授权；明星脸、网红脸一律别碰。
- **GPU 是硬门槛**：没有 3060 级别的 N 卡基本没法实时玩；云 GPU 按小时计费，长期直播要算清成本。
- **241 个 open issue**：项目活跃但问题也多，遇到坑先翻 FAQ 与 issue；文档站点是 doc.livetalking.ai。
- **声音克隆的合规**：克隆他人声音需授权，用 AI 声音做带货口播，平台可能要求标注。
