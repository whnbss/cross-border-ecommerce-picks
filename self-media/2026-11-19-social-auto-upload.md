## 一句话

基于 Playwright 的浏览器自动化，把同一批视频批量发布到抖音、B站、小红书、视频号、快手、TikTok、YouTube 等平台（具体平台清单以仓库 README 为准），自带 `sau` 命令行与 cookie 管理。

## 适合谁

做矩阵号、批量铺内容、给客户代运营账号的人。

## 变现路径

1. **代运营 / 代发布**（启动成本：账号 + 网络，难度低）：客户给素材，你按平台矩阵铺出去，按月收服务费。
2. **矩阵号自营**（启动成本：多号注册与养号，难度中）：一套内容多平台分发，摊薄单条制作成本，靠平台分成与带货佣金变现。
3. **起号服务**（启动成本：时间，难度中）：新号冷启动期的定时发布 + 多号管理，按号收费。

## 落地步骤

1. `git clone` 仓库，按 README 装 Python 依赖
2. 用 `sau` 登录目标平台并保存 cookie
3. 只挑一个平台小批量试发，确认标题/封面/话题不被限流
4. 再扩到多平台、多账号
5. 用系统定时任务做每日固定时段发布

## 风险

- 平台对自动化发布有风控，账号可能被限流或封禁；控制频率，不要跨设备频繁切登录
- 小红书 / 视频号等登录态有效期短，需要定期续 cookie
- 最近推送为 2026-10，平台改版后接口可能失效，正式用之前先小号验证
